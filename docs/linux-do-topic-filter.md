# LINUX DO 帖子过滤器

为 `https://linux.do` 的帖子列表增加标题、标签和类别过滤，并在保存设置前预览当前页面的过滤结果。

## 安装

浏览器须先安装 Tampermonkey、Violentmonkey 或同类用户脚本扩展，而后打开 [脚本安装地址](https://raw.githubusercontent.com/fanjindong/houmao/main/scripts/linux-do-topic-filter.user.js) 并确认安装。

## 使用

1. 打开任一 LINUX DO 页面。
2. 在用户脚本扩展菜单中选择“设置帖子过滤词”。
3. 分别填写标题过滤词、类别名称和标签名称，每行一个。
4. 在下方查看当前已加载帖子中的命中结果。
5. 点击“保存并应用”。

标题采用不区分大小写的子串匹配，标签采用不区分大小写的完整名称匹配；类别除匹配完整名称外，父类别规则也会匹配其子类别。任一规则命中便会隐藏帖子。取消编辑不会改变现有设置；清空三个文本框并保存可恢复全部帖子。

脚本会自动处理页面切换和无限滚动新加载的帖子。有过滤规则时，同一批新帖子会保留布局高度并暂时隐藏，在 DOM 停止变化后统一完成过滤判断；未命中的帖子只显示一次且保持稳定。预览只包含当前已经加载的帖子，不会主动请求后续分页。

## 隐私

过滤词只保存在用户脚本扩展的本地存储中。脚本不发网络请求，也不读取 Cookie、localStorage 或登录信息。
