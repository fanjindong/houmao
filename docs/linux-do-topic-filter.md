# LINUX DO 帖子过滤器

为 `https://linux.do` 的帖子列表增加标题、标签和类别过滤，通过侧栏查看实际过滤记录、编辑规则并预览草稿结果。

## 安装

浏览器须先安装 Tampermonkey、Violentmonkey 或同类用户脚本扩展，而后打开 [脚本安装地址](https://raw.githubusercontent.com/fanjindong/houmao/main/scripts/linux-do-topic-filter.user.js) 并确认安装。

## 使用

1. 打开任一 LINUX DO 页面。
2. 点击帖子列表工具栏中的“过滤 N”，打开侧栏；也可在用户脚本扩展菜单中选择“设置帖子过滤词”。
3. 切换至“规则设置”，分别添加标题关键词、类别和标签。输入后按回车或点击“添加”，也可一次粘贴多行；点击词条上的 × 删除。
4. 在下方“草稿预览”查看预计过滤的帖子。尚未按回车的输入也会参与预览，并在保存时加入规则。
5. 点击“保存”让新规则用于后续加载；点击“保存并刷新”则在保存成功后刷新当前页面，整张列表采用新规则。

标题采用不区分大小写的子串匹配，标签采用不区分大小写的完整名称匹配；类别除匹配完整名称外，父类别规则也会匹配其子类别。除设为“始终保留”的帖子外，任一规则命中便不会进入帖子列表。重复词条按不区分大小写去重；类别名称中的逗号保留原样。

切换“过滤记录”“规则设置”或进入保留清单时，草稿继续保留；关闭侧栏会放弃尚未保存的草稿。删除全部词条并保存后，后续加载的帖子不再过滤。旧版本已保存的规则与保留清单会直接沿用。

脚本在 LINUX DO 渲染前处理首屏预载数据，以及页面切换和无限滚动取得的帖子接口数据。“保存”成功后，侧栏提示“已保存，将用于后续加载”，当前列表保持原样；切回已缓存的页面时，可用“保存并刷新”或手动刷新应用新规则。预览只包含已经取得的帖子，不会主动请求后续分页。保存失败会保留草稿并显示错误，不执行刷新。

## 查看过滤记录

列表工具栏显示“过滤 N”，侧栏的“过滤记录”页显示读取总数及实际过滤数。数量按帖子 ID 去重，以本次打开站点后、当前列表中每个帖子最近一次处理的结果为准；滚动加载会继续累计。尚未收到帖子列表数据时显示“本页尚未取得帖子数据”；已有数据且没有命中时显示“这一页没有命中规则”。切换不同列表时，入口显示对应列表的数量；刷新页面会重新统计。

每条记录列出帖子标题及标题、标签或类别的命中原因；点击标题可在新标签页打开。记录保留处理当时的原因，“草稿预览”则按当前输入重新计算，两者彼此独立。

## 始终保留单帖

在过滤记录右侧点击“⋯”，选择“始终保留此帖”。保存成功后，该帖子优先于标题、标签和类别规则放行。此操作立即保存，后续加载便会生效；点击提示中的“刷新”可将它恢复到当前主列表。刷新前，原过滤记录仍保留，并标明“已保留”。

侧栏顶部“⋯”菜单中的“保留清单”列出全部放行帖子。通过某条帖子的“⋯ → 取消保留”恢复规则判断，点击“返回”回到原页签。放行设置跨刷新保留，与过滤词草稿分别保存；保存失败会显示错误并维持原有保留设置。

## 窄屏与键盘操作

窄屏下侧栏铺满屏幕，内容区独立滚动，保存按钮固定在底部。页签支持左右方向键及 Home、End；更多菜单支持上下方向键。Escape 先关闭已展开的菜单，再关闭侧栏；保存进行中会等待写入完成。

## 隐私

过滤词及始终保留的帖子 ID、标题只保存在用户脚本扩展的本地存储中；本次浏览的原始帖子和过滤记录只保留在内存中。脚本不发起额外网络请求，也不读取 Cookie、localStorage 或登录信息；它只在浏览器内过滤站点自身取得的帖子列表数据。
